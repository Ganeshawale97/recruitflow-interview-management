# RecruitFlow — Interview Management System

A browser-based prototype for managing college club recruitment interviews across multiple waiting rooms and interview panels.

## Features

- Candidate registration and management
- Up to 4 domain choices
- Venue entry
- Waiting Room 1 and 2
- Priority queue
- 11 interview panels
- Interviewer evaluation
- Domain-wise scores
- Automatic return to Waiting Room 2
- Final allocation
- LocalStorage persistence

## Run

Open index.html in a modern browser.

## Production note

A production version should use a backend database, authentication, role permissions, audit logs, and real-time synchronization.
